## 一、初识 Arduino 主板

### 1. 什么是单片机
>单片机（MCU）就是**把一台电脑的核心部件塞进一块芯片里**：CPU、内存、闪存、定时器、输入输出接口，全都在同一颗芯片上。

Arduino UNO 的主控芯片是 **ATmega328P**，它有这些家底：

| 项目 | 参数 | 大致相当于 |
| --- | --- | --- |
| 主频 | 16 MHz | 比 90 年代的 486 还慢 |
| 闪存 Flash | 32 KB | 你写的程序存在这里 |
| 内存 RAM | 2 KB | **非常小**，省着用 |
| 工作电压 | 5V | |

它和我们平时用的电脑有本质区别：

| | 电脑 | 单片机 |
| --- | --- | --- |
| 操作系统 | Windows / Linux | **没有**，程序裸跑 |
| 开机后 | 进入桌面等你操作 | 上电就开始执行你写的代码 |
| 关机 | 关机 | 断电即停，重新上电从头再来 |
| 用途 | 通用计算 | 专门控制硬件（点灯、读传感器、驱动电机） |

所以写单片机的思路要转过来：**你写的是"上电以后一直循环做什么"，而不是"打开软件点什么按钮"。**

### 2. 主板上的三个关键概念

#### （1）Type-B 电源接口
主板边上那个**方形的大 USB 口**，叫 **USB Type-B**（也叫方口、打印机口）。

它**一根线干三件事**：

| 作用 | 说明 |
| --- | --- |
| 供电 | 给整块板子供电，板上的 PWR 灯亮起 |
| 下载程序 | 电脑里编译好的代码，通过它烧进芯片 |
| 串口通信 | 板子和电脑互相发数据，用来调试打印 |

> **注意**：除了 USB 口，板子还有一个**圆形的 DC 电源口**，可以接 7~12V 的电源适配器或电池盒（接在你标着 VIN 的位置）。社团实训时两根线别同时乱插。

> 替换为：`![Type-B 接口与 DC 电源口](images/air-club-day1-usb.jpg)`

#### （2）排针
>主板两侧那一排排**竖着的小金属针**，就叫**排针**。它是主板和外部世界连接的"插座"。

用**杜邦线**（一头是塑料壳的插头）插上去，就能把传感器、LED、电机接到主板上。

按功能分三组：

| 排针组 | 丝印标识 | 作用 |
| --- | --- | --- |
| 数字排针 | 0 ~ 13、GND、AREF | 接开关、LED、继电器；编号带 `~` 的（3/5/6/9/10/11）能做 PWM |
| 模拟排针 | A0 ~ A5 | 接电位器、光敏、温度等**连续变化**的信号 |
| 电源排针 | VIN、GND、5V、3.3V、RESET | 给外部模块供电、复位主板 |

> 📷 **图 3 ｜ 数字排针 / 模拟排针 / 电源排针三组标识**（图片位置预留）
> 替换为：`![三组排针标识](images/air-club-day1-pins.jpg)`

#### （3）5V、3.3V 和地（GND）
这三个是**电源排针**上最容易接错、接错就烧东西的位置。

| 标识 | 含义 | 给谁用 | 注意 |
| --- | --- | --- | --- |
| **5V** | 5 伏正电源 | 大部分 5V 模块、传感器 | 输出电流受 USB 供电限制 |
| **3.3V** | 3.3 伏正电源 | 3.3V 的逻辑模块 | **输出能力很小（约 50mA）**，带不动电机 |
| **GND** | 地，也就是 0V 参考点 | 所有电路的公共负极 | **必须共地**，不共地通信会乱码或直接不工作 |
| VIN | 外部电源输入 | 接电池 / 适配器 7~12V | 极性接反会烧板 |

**记住一句话就够了：所有模块的 GND 必须和主板的 GND 连在一起。** 这是后面学串口、I2C 一切通信的前提。

> **<span style="color: red;">红色警告：</span>** VCC（正极）和 GND 接反，模块当场报废。接线前先确认颜色——一般**红线是正、黑线是地**，但不要只信颜色，要看丝印。

## 二、Arduino IDE 的下载与基础布局

### 1. 下载安装
1. 打开官网 `https://www.arduino.cc/en/software`
2. 下载 **Arduino IDE 2.x** 的 Windows 安装包
3. 双击安装，一路默认
4. 插上主板，看到「设备管理器 → 端口」里出现 `COMx` 就说明驱动正常

> 如果出现带黄色感叹号的未知设备，说明缺 **CH340 驱动**——国产兼容板大多用 CH340 芯片，需要单独装驱动。

### 2. 界面基础布局
打开 IDE 后，认这 5 个区域就够了：

| 区域 | 位置 | 做什么 |

## 三、写下第一段代码

### 1. `setup()` 和 `loop()` 分别干什么

打开 IDE 新建项目，你会看到两个空函数——这就是 Arduino 程序的骨架：

| 函数 | 什么时候执行 | 用来做什么 |
| --- | --- | --- |
| `void setup()` | 上电或按复位后，**只执行一次** | **配置**：设置引脚模式、打开串口、初始化传感器 |
| `void loop()` | setup 执行完后，**无限循环** | **干活**：主逻辑写在这里 |

一句话记：**setup 是配置，loop 是工作循环。**

```cpp
void setup() {
  // 只跑一次：配置
}

void loop() {
  // 一直循环：干活
}
```

### 2. 今天学的三个函数

| 函数 | 作用 | 参数 |
| --- | --- | --- |
| `pinMode(pin, mode)` | 告诉主板这个引脚**是输入还是输出** | `OUTPUT` / `INPUT` |
| `digitalWrite(pin, value)` | 让引脚**输出高电平或低电平** | `HIGH`（5V）/ `LOW`（0V） |
| `delay(ms)` | **阻塞**等待若干毫秒 | 1000 = 1 秒 |

### 3. 完整代码：让 13 号脚的灯闪起来

Arduino UNO 板上自带一颗贴片 LED，就接在 **13 号引脚**上（板子上丝印标着 `L`），所以不用接线也能看到效果。

```cpp
void setup() {
  pinMode(13, OUTPUT);       // 把 13 号脚配置成输出
}

void loop() {
  digitalWrite(13, HIGH);    // 输出高电平 → 灯亮
  delay(1000);               // 保持亮 1 秒
  digitalWrite(13, LOW);     // 输出低电平 → 灯灭
  delay(1000);               // 保持灭 1 秒
}
```

> **为什么 `HIGH` 是"亮"？** 因为这颗 LED 的**阳极（正极）接在 13 号脚，阴极经限流电阻接地**。所以 13 号脚输出高电平（5V）时，电流从引脚流过 LED 到地，灯就亮——这叫**高电平有效**。如果哪天遇到"低电平才亮"的模块，那是接法不同，不能照搬。

点 ✅ 验证，再点 ➡️ 上传，板子上 TX/RX 灯闪一下，13 号脚的 LED 就会 1 秒一闪。

### 4. 想通了：为什么要写两个 delay

这是今天最重要的一个瞬间。三种写法对比一下：

**写法一：一个 delay 都不写**
```cpp
void loop() {
  digitalWrite(13, HIGH);
  digitalWrite(13, LOW);
}
```
这两行执行完只要几微秒，然后立刻从头再来。灯在亮灭之间每秒切换几十万次，人眼完全分辨不出来——**看起来就是不亮（或者微微发暗）**。

**写法二：只写一个 delay**
```cpp
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);
  digitalWrite(13, LOW);
}
```
亮 1 秒，灭的时间几乎为 0，然后马上又亮——**看起来就是常亮**。

**写法三：两个 delay**
```cpp
void loop() {
  digitalWrite(13, HIGH);
  delay(1000);              // 亮多久
  digitalWrite(13, LOW);
  delay(1000);              // 灭多久
}
```
这才是一个完整、人眼能看清的周期：

```
亮 1s → 灭 1s → 亮 1s → 灭 1s → ...
└────── 一个完整周期 = 2 秒 ──────┘
```

所以结论是：

- **第一个 delay 决定"亮多久"**
- **第二个 delay 决定"灭多久"**
- 少任何一个，闪烁都不成立

**进阶思考**：如果两个 delay 不一样长呢？比如亮 200ms、灭 800ms，灯亮的时间只占 20%，肉眼看起来就**明显偏暗**。这就是后面要学的 **PWM 调光**的雏形——改变"亮"和"灭"的时间比例，就能得到不同亮度。

## 四、Tinkercad 仿真

手边没板子也能练。今天我们注册了 **Tinkercad** 并加入班级，用网页仿真把上面的代码跑了一遍。

### 1. 注册并加入班级
1. 打开 `https://www.tinkercad.com/`
2. 注册账号（可以用邮箱，也可以用 Google 账号）
3. 在 **Classes（班级）** 里找到社团的班级，用老师给的**班级代码**或**邀请链接**加入

### 2. 在仿真里复现代码
1. 进入 **Circuits（电路）→ Create new Circuit**
2. 从右侧元件库拖入：**Arduino UNO R3**、**面包板**、**LED**、**电阻（220Ω）**
3. 按图接线：LED 长脚 → 13 号脚，短脚 → 电阻 → GND
4. 切到 **Code（代码）** 视图，选 **Text** 模式，粘贴上面那段代码
5. 点 **Start Simulation**，仿真里的 LED 就会开始闪烁

> **仿真最大的好处**：接错线、烧不坏东西。可以大胆试。但要注意——**仿真里"能亮"不代表真机一定对**，真实电路还要考虑电流、电阻取值和接触不良。
