> **本文环境**：STC8H8K64U（增强型 8051 内核）＋ Keil C51 ＋ STC-ISP 下载软件
> **适合读者**：有 C 语言基础，想从「教科书上的 8051」过渡到真正能用的芯片
> **一个重要提醒**：STC8H 虽然「指令集兼容 8051」，但**寄存器、IO 模式、定时器模式都和老 8051 不一样**，照抄教材代码大概率点不亮灯。本文重点就讲这些差异。

## 一、认识 51 单片机与 STC8H

### 1. 什么是 51 单片机
51 单片机最早是 Intel 的 8051，是**8 位机时代的绝对主力**。它的架构简单、寄存器少、资料多，至今仍是**入门嵌入式的第一块敲门砖**。

**STC8H 做了什么改进**（依据[官方 STC8H8K64U 页面](https://stcmicro.com/cn/stc/stc8h8k64u.html)）：

| 项目 | 传统 8051（如 AT89C51） | STC8H8K64U |
| --- | --- | --- |
| 指令执行 | 12 个时钟周期一条 | **1 个时钟周期一条（1T）** |
| 速度 | 12MHz ≈ 1MIPS | 同样频率下**约快 12 倍** |
| Flash | 4KB 需专用编程器 | **64KB，支持 ISP 串口下载** |
| 内部 RAM | 128 字节 | **8KB 扩展 RAM** |
| 硬件外设 | 基本没有 | 12 位 ADC、高级 PWM、4 串口、USB |

**<span style="color: red;">核心结论：</span>** STC8H 是「**8051 的指令集 ＋ 现代单片机的性能**」。你会写 8051 汇编/C51，就能直接用它；但**配置寄存器的方式完全是新的**。

### 2. 型号怎么读：STC8H8K64U
这个命名拆开看，每个字母都有含义：

| 片段 | 含义 |
| --- | --- |
| **STC** | 厂商：宏晶科技 |
| **8H** | 系列：STC8H 系列（增强型 8051） |
| **8K** | **内部扩展 RAM = 8KB**（8192 字节 XDATA） |
| **64** | **Flash 程序存储器 = 64KB** |
| **U** | 带 **USB**（全速 USB 2.0） |

同系列还有 **8K32U / 8K48U / 8K60U**，区别只在 Flash 大小（32/48/60KB），SRAM 都是 8.2K。

> **<span style="color: red;">注意：</span>** 型号里的 `8K` 指的是 **RAM（内存）**，不是 Flash！很多人以为是 8KB Flash，买回来发现 Flash 是 64KB。反过来说，**RAM 只有 8KB 也决定了你不能定义太大的数组**。

### 3. 官方主要参数

| 项目 | 参数 |
| --- | --- |
| 内核 | 超高速 8051（1T），指令完全兼容传统 8051 |
| 工作电压 | 1.9V ~ 5.5V |
| 工作温度 | -40℃ ~ 85℃ |
| Flash | 最大 64KB（可划分部分做 EEPROM，擦写 10 万次以上） |
| SRAM | 128B DATA ＋ 128B IDATA ＋ **8192B 扩展 RAM** ＋ 1280B USB RAM |
| 时钟 | 内部高精度 IRC **4MHz ~ 45MHz**（误差 ±0.3%），也可用外部晶振 |
| GPIO | **60 个**（P0~P7，其中没有 P1.2） |
| 定时器 | 5 个 16 位（T0~T4） |
| 串口 | **4 个**高速串口 |
| ADC | 12 位、15 通道，最快 800K 次/秒 |
| PWM | 8 路 / 2 组高级 PWM（带死区控制） |
| 其他 | SPI、I2C、比较器、USB、DMA、LCM 彩屏驱动 |
| 封装 | LQFP64 / QFN64 / LQFP48 / QFN48 |

### 4. ★ 和教科书 8051 的三个致命差异
这一节请仔细看，**90% 的新手点不亮灯都栽在这里**。

**差异一：I/O 上电默认是「高阻输入」，不是准双向口**

官方原文：**「除 P3.0 和 P3.1 外，其余所有 I/O 口上电后的状态均为高阻输入状态，用户在使用 I/O 口时必须先设置 I/O 口模式。」**

传统 8051 的 P1、P2 上电默认是准双向口，直接写 0/1 就有输出。**STC8H 不行**——不配置模式，引脚就是「悬空」，接 LED 一点反应都没有。

**差异二：定时器「模式 0」是 16 位自动重载**

传统 8051 的 T0 模式 0 是 13 位定时器；STC8H 的**模式 0 变成了 16 位自动重载**。所以 `TMOD` 的写法虽然一样，实际行为完全不同，**不能再照抄教材的初值计算**。

**差异三：内部扩展 RAM 要认 `xdata`**

STC8H 有 8192 字节扩展 RAM，但它不在 8051 的 128 字节直接寻址空间里。要用它，变量必须声明为 `xdata`——否则你只能用到可怜的 128 字节。

## 二、开发环境搭建

### 1. 需要两个软件
51 单片机的工具链和 Arduino 不一样，是**写代码**和**烧录**分开的两个软件：

| 软件 | 作用 | 获取 |
| --- | --- | --- |
| **Keil C51**（uVision） | 写代码、编译、生成 .hex | Keil 官网（有评估版，2KB 代码限制） |
| **STC-ISP** | 把 .hex 下载进芯片、设置时钟、生成初始化代码 | STC 官网免费下载（v6.88 ~ v6.91） |

> **新手最省事的组合**：Keil C51（v9 或 v5）＋ STC-ISP v6.9x。

### 2. 新建 Keil 工程
1. 打开 Keil → **Project → New uVision Project**
2. 选一个保存目录，工程名随意
3. **选芯片**：列表里找 `STC MCU Database` 下的 **STC8H8K64U**
   - 如果找不到 STC 芯片：打开 STC-ISP →「**Keil 仿真设置**」→「**添加型号和头文件到 Keil 中**」，指定 Keil 安装目录即可
   - 实在不行：随便选 `Atmel → AT89C52`，然后**手动把 `STC8H.H` 放到工程目录并 include**
4. 新建 `main.c`，加入工程
5. 在 **Options for Target → Output** 里**勾选 Create HEX File**（不勾就没有 .hex，STC-ISP 无法下载）

### 3. 用 STC-ISP 下载（关键：冷启动）
STC 的下载方式和 Arduino 完全不同，**必须先点「下载」再给板子上电**：

1. 板子**先断电**（或者拔掉电源）
2. 打开 STC-ISP，左侧顶部选芯片型号 **STC8H8K64U**
3. 选 **串口号**（USB 转串口模块对应的 COM 口）
4. 点「**打开程序文件**」→ 选你编译出的 `.hex`
5. 点「**下载/编程**」
6. 这时 STC-ISP 会显示「正在等待单片机复位」，**此时给板子上电**
7. 下载完成，程序自动运行

> **<span style="color: red;">为什么必须冷启动？</span>** STC 单片机上电时会先检测串口有没有下载命令（约几十毫秒）。程序一旦跑起来就不再检测了，所以必须「断电 → 点下载 → 上电」。

**下载失败的排查顺序：**

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 一直「等待单片机复位」 | 没断电重上电 | 严格按「先点下载，再上电」 |
| 提示「串口已被占用」 | 别的软件占着串口 | 关掉串口助手/另一个 STC-ISP |
| 找不到串口 | 缺 USB 转串口驱动 | 装 CH340 驱动 |
| 下载成功但不运行 | 时钟设置/复位脚设错 | 硬件选项里检查 |

### 4. 时钟设置（在 STC-ISP 的「硬件选项」里）
STC8H 出厂使用**内部 IRC 时钟**，频率在 STC-ISP 的「硬件选项」里选（**4MHz ~ 45MHz**，也可手动输入）。

**<span style="color: red;">这一步直接决定你的定时器和串口波特率对不对。</span>** 如果你代码里按 24MHz 算的时间，而芯片实际配的是 11.0592MHz，定时就会差一倍多。

> **建议做法**：初学固定用 **24MHz**（或 11.0592MHz，串口波特率更好算），并在代码注释里写清楚，避免以后混乱。

### 5. USB 直接下载（8K64U 的福利）
型号里的 **U** 表示支持 USB。STC8H8K64U 可以直接用 USB 线连电脑下载程序，**不需要 USB 转串口模块**：
- 用 STC 的 **USB-ISP** 下载软件
- 芯片内部有 USB 控制器，电脑会识别成一个 USB 设备

> 这也是「8K64U」比没有 U 的型号贵一点的原因。

## 三、C51 语言要点（和标准 C 的差异）

### 1. 数据类型
Keil C51 的数据类型和标准 C 基本一致，但要注意**长度**：

| 类型 | 位数 | 范围 | 说明 |
| --- | --- | --- | --- |
| `bit` | 1 位 | 0 / 1 | **C51 特有**，只能放位寻址区 |
| `unsigned char` / `u8` | 8 | 0 ~ 255 | 最常用 |
| `unsigned int` / `u16` | **16** | 0 ~ 65535 | **注意：C51 里 int 是 16 位，不是 32 位！** |
| `long` | 32 | ±21 亿 | 慢，尽量少用 |
| `float` | 32 | — | 更慢，能不用就不用 |

> **重点：C51 的 `int` 只有 16 位**，最大 65535。做累加很容易溢出，需要大数用 `unsigned long`。

### 2. ★ 存储类型（决定变量放哪里）
这是 C51 和标准 C **最大的区别**，也是最容易踩坑的地方：

| 关键字 | 存放位置 | 特点 | 用途 |
| --- | --- | --- | --- |
| `data` | 内部 RAM 低 128B | **最快**（直接寻址） | 频繁访问的小变量 |
| `idata` | 内部 RAM 全部 256B | 较快（间接寻址） | |
| `xdata` | **外部/扩展 RAM（8KB）** | 慢一些，但**容量大** | **大数组、缓冲区** |
| `code` | Flash（程序区） | 只读 | **常量表、字库** |

```c
unsigned char  buf[16];               // 默认在 data 区，总共只有 128B，容易爆
unsigned char xdata bigBuf[1024];     // 放到 8KB 扩展 RAM
const unsigned char code font[] = {0x00};  // 常量放 Flash，不占 RAM
```

> **<span style="color: red;">必看：</span>** 不加 `xdata` 的数组默认挤在 128 字节里。写个 `unsigned char buf[200];` 编译会直接报「DATA space overflow」。**看到这个报错，就是该加 `xdata` 了。**

### 3. sfr / sbit：直接操作寄存器
```c
sfr  P1   = 0x90;      // 定义特殊功能寄存器（地址见手册）
sbit LED  = P1^0;      // 定义 P1.0 这一位
```
实际上这些都在 `STC8H.H` 里定义好了，你只要 `#include <STC8H.H>` 就能直接用 `P1`、`P1M0` 等名字。

### 4. 中断函数：interrupt n
C51 用关键字声明中断服务函数，**n 是中断号**：

| 中断源 | 中断号 |
| --- | --- |
| INT0（外部中断 0） | 0 |
| **定时器 0** | **1** |
| INT1 | 2 |
| 定时器 1 | 3 |
| **串口 1** | **4** |
| ADC | 5 |
| 定时器 2 | 12 |

```c
void Timer0_ISR(void) interrupt 1 {
    // 定时器 0 中断
}
```

**三条铁律：**
1. 中断函数**不能有参数、不能有返回值**
2. 函数体要**短**，不要在里面做长延时或浮点运算
3. 主函数里的全局变量如果在中断中修改，最好加 `volatile`

### 5. 扩展寄存器与 P_SW2
STC8H 有一部分寄存器不在标准 SFR 空间（叫 XFR，扩展寄存器）。访问它们前要把 `P_SW2` 的最高位置 1：

```c
P_SW2 |= 0x80;    // 使能扩展寄存器访问（EAXFR）
```

> 普通的 `P1`、`P1M0`、`TMOD`、`SCON` 这些**不需要**；但配置高级 PWM、部分 ADC 参数时通常需要。**忘了这一句，写进去的值会「丢失」。**

## 四、GPIO 操作（重点）

### 1. 四种端口模式
每个端口有两组配置寄存器：**`PxM1`** 和 **`PxM0`**（x = 0~7）。用这两个位的组合决定引脚模式：

| PxM1 | PxM0 | 模式 | 说明 | 典型用途 |
| --- | --- | --- | --- | --- |
| 0 | 0 | **准双向口**（弱上拉） | 最接近传统 8051，输入输出都能用 | 普通 IO、按键 |
| 0 | 1 | **强推挽输出** | 驱动能力强（可达 20mA），只能输出 | 驱动 LED、蜂鸣器 |
| 1 | 0 | **高阻输入** | 只做输入，不影响外部电路 | **ADC 采样、读传感器** |
| 1 | 1 | **开漏输出** | 需要外部上拉电阻 | I2C 总线 |

> **记忆口诀**：「**准双向、强推挽、高阻入、开漏出**」，对应 00、01、10、11。

### 2. 点灯（第一个程序）
```c
#include <STC8H.H>

sbit LED = P1^0;          // LED 接在 P1.0

void Delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 1000; j++);   // 需按实际主频校准
}

void main(void) {
    // ★ 第一步永远是配置 IO 模式！上电默认是高阻输入
    P1M0 = 0x00;
    P1M1 = 0x00;          // P1 全部设为「准双向口」

    while (1) {
        LED = 0;          // 低电平 → 电流从 VCC 流过 LED 到 P1.0 → 灯亮
        Delay_ms(500);
        LED = 1;          // 高电平 → 两端都是高 → 灯灭
        Delay_ms(500);
    }
}
```

**接线有两种，逻辑相反，别搞混：**

| 接法 | LED 阳极 | LED 阴极 | 点亮条件 |
| --- | --- | --- | --- |
| **灌电流**（推荐） | 接 VCC（串 1kΩ 电阻） | 接 P1.0 | **`LED = 0`** 亮 |
| **拉电流** | 接 P1.0（串 1kΩ 电阻） | 接 GND | **`LED = 1`** 亮 |

> **为什么要串电阻？** 限制电流。不串电阻，LED 和 IO 口都可能烧掉。STC8H 单个 IO 建议不超过 **20mA**。
> **灌电流比拉电流好**：准双向口的高电平是「弱上拉」（约几十 μA），推不动 LED；低电平是真正的 NMOS 下拉，能灌 20mA。所以**优先用灌电流接法**。

### 3. 按键输入
```c
#include <STC8H.H>

sbit KEY = P3^2;          // 按键接 P3.2，另一端接 GND
sbit LED = P1^0;

void Delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 1000; j++);
}

void main(void) {
    P3M0 = 0x00; P3M1 = 0x00;     // P3 准双向口（内部弱上拉）
    P1M0 = 0x00; P1M1 = 0x00;

    while (1) {
        if (KEY == 0) {           // 按下时接地，读到低电平
            Delay_ms(20);         // ★ 消抖
            if (KEY == 0) {
                LED = !LED;       // 翻转
                while (KEY == 0); // 等松手，避免连击
            }
        }
    }
}
```

> **准双向口的原理**：它内部有弱上拉，引脚悬空时读到 **1**；被外部拉低时读到 **0**。所以按键一端接 GND 就够了，不用外部上拉电阻——但**前提是把引脚设成准双向口或高阻输入**（高阻输入没有上拉，需要外部电阻）。

### 4. 上电高阻这个坑，再强调一次
```c
// ❌ 错误：没配模式，灯不亮
void main(void) {
    P1 = 0x00;        // 想拉低所有 P1 口 → 实际没反应
    while (1);
}

// ✅ 正确：先配置模式
void main(void) {
    P1M0 = 0xFF;      // 推挽输出
    P1M1 = 0x00;
    P1 = 0x00;
    while (1);
}
```

## 五、定时器与中断

### 1. 定时器的时钟从哪来
STC8H 的定时器默认是「**12T 模式**」——即每 12 个系统时钟计一次数（和传统 8051 兼容）。可以通过 `AUXR` 的 `T0x12` / `T1x12` 位改成 **1T**（更快）。

**定时时间计算公式（12T）：**

```
计数频率 = SYSclk / 12
定时时间 = (65536 - 初值) / 计数频率
初值     = 65536 - 定时时间 × SYSclk / 12
```

**举例**：主频 24MHz，定时 1ms
- 计数频率 = 24MHz / 12 = 2MHz
- 需要计数 2000 次
- 初值 = 65536 - 2000 = **63536 = 0xF830**
- 所以 `TH0 = 0xF8`、`TL0 = 0x30`

### 2. 定时器中断闪灯
```c
#include <STC8H.H>

sbit LED = P1^0;
unsigned int cnt = 0;

void Timer0_Init(void) {
    TMOD = (TMOD & 0xF0) | 0x00;   // T0 模式 0 = 16 位自动重载（STC8H 特有！）

    TL0 = 0x30;                    // 24MHz / 12 = 2MHz，1ms → 2000 次
    TH0 = 0xF8;                    // 65536 - 2000 = 0xF830

    TR0 = 1;                       // 启动定时器
    ET0 = 1;                       // 允许 T0 中断
    EA  = 1;                       // 开总中断
}

void Timer0_ISR(void) interrupt 1 {
    // 16 位自动重载模式：不用手动重装初值
    cnt++;
    if (cnt >= 500) {              // 500 × 1ms = 500ms
        cnt = 0;
        LED = !LED;
    }
}

void main(void) {
    P1M0 = 0x00; P1M1 = 0x00;
    Timer0_Init();
    while (1) {
        // 主循环空着，灯也会闪——这就是中断的好处
    }
}
```

> **<span style="color: red;">注意：</span>** 因为是**自动重载**模式，中断里**不需要**再写 `TH0 = 0xF8; TL0 = 0x30;`。如果你照抄教材加了这两句，反而会让定时变慢（多消耗几十个时钟周期）。

### 3. 中断优先级
STC8H 有 **4 级中断优先级**（传统 8051 只有 2 级）。通过 `IP`、`IPH` 寄存器设置。初学阶段用默认优先级（同级按自然顺序）就够了。

## 六、串口

### 1. 原理
串口（UART）是 51 最常用的通信方式：**异步、无时钟线、双方波特率必须一致**。

- 接线：**TX 接对方 RX，RX 接对方 TX，GND 必须共地**
- STC8H 有 4 个串口（串口1~4）
- 波特率由**定时器**产生（串口1 可用 T1 或 T2）

### 2. 串口1 初始化（用定时器2 做波特率）
```c
#include <STC8H.H>
#include <stdio.h>

void UART1_Init(void) {
    SCON = 0x50;        // 模式1：8 位数据、可变波特率、允许接收
    // 波特率 = SYSclk / (65536 - [T2H,T2L]) / 4
    // 24MHz → 115200 约需 52 个计数 → 65536-52 = 65484 = 0xFFCC
    T2H = 0xFF;
    T2L = 0xCC;

    AUXR |= 0x01;       // 串口1 选用 T2 作为波特率发生器 (S1ST2)
    AUXR |= 0x04;       // T2 工作在 1T 模式 (T2x12)
    AUXR |= 0x10;       // 启动 T2 (T2R)

    ES = 1;             // 允许串口1 中断
    EA = 1;             // 开总中断
}

void UART1_ISR(void) interrupt 4 {
    unsigned char dat;
    if (RI) {
        RI = 0;
        dat = SBUF;     // 读出收到的字节
        SBUF = dat;     // 原样发回（回显）
    }
    if (TI) {
        TI = 0;         // 发送完成标志必须手动清零
    }
}
```

> **<span style="color: red;">波特率一定要用工具算：</span>** 上面的 `0xFFCC` 是按 **24MHz** 算的。改主频后必须重算——最稳的办法是用 **STC-ISP 里的「波特率计算器」**，选好芯片、主频、波特率，它会直接把初始化代码生成出来，复制粘贴即可。

### 3. printf 重定向（调试神器）
C51 默认的 `printf` 输出到哪需要你指定。加下面这个函数，就能用 `printf` 直接往串口打印：

```c
char putchar(char c) {
    SBUF = c;
    while (!TI);        // 等发送完成
    TI = 0;
    return c;
}
```

之后就可以：

```c
void main(void) {
    P1M0 = 0x00; P1M1 = 0x00;
    UART1_Init();

    printf("Hello STC8H!\r\n");
    printf("ADC = %u\r\n", 1234);

    while (1);
}
```

> **注意**：用 `printf` 会多占不少 Flash。64KB 的 Flash 够用，但如果你在 4KB 的芯片上，尽量改用自己写的打印函数。

## 七、PWM 与 ADC

### 1. PWM 是什么
PWM（脉冲宽度调制）就是**快速地开关**，用「开的时间占多少比例」（**占空比**）来等效出不同电压。

- 占空比 100% → 等效全电压（灯最亮）
- 占空比 50% → 等效一半电压
- 占空比 0% → 全关（灯灭）

用途：**调 LED 亮度、调电机转速、控制舵机**。

### 2. 先用定时器实现软件 PWM（理解原理）
```c
#include <STC8H.H>

sbit LED = P1^0;
unsigned char duty   = 0;     // 占空比 0~255
unsigned char pwmCnt = 0;
bit dir = 0;                  // 呼吸方向

void Timer0_Init(void) {
    TMOD = (TMOD & 0xF0) | 0x00;
    // 100us 一次中断：24MHz/12 = 2MHz，100us = 200 次
    // 65536 - 200 = 65336 = 0xFF38
    TL0 = 0x38;
    TH0 = 0xFF;
    TR0 = 1; ET0 = 1; EA = 1;
}

void Timer0_ISR(void) interrupt 1 {
    pwmCnt++;
    LED = (pwmCnt < duty) ? 0 : 1;    // 灌电流接法：低电平亮

    if (pwmCnt == 0) {                // 每个周期调整一次亮度
        if (dir == 0) { duty++; if (duty == 255) dir = 1; }
        else          { duty--; if (duty == 0)   dir = 0; }
    }
}

void main(void) {
    P1M0 = 0xFF; P1M1 = 0x00;         // P1 推挽输出（驱动 LED 更强）
    Timer0_Init();
    while (1);
}
```

> **这个例子的价值在于「看懂 PWM 原理」**：定时器每 100μs 中断一次，计数到 256 次就是一个完整周期（约 25.6ms，即 39Hz）。期间 `pwmCnt < duty` 的时间灯亮，其余时间灭——这就是占空比。
> **缺点**：占用 CPU，频率低，肉眼能看到轻微闪烁。正式项目要用硬件 PWM。

### 3. 硬件高级 PWM（PWMA / PWMB）
STC8H 有 **8 路 / 2 组高级 PWM**，功能很强（带死区控制、互补输出、外部捕获），但**配置比较繁琐**：

| 寄存器 | 作用 |
| --- | --- |
| `PWMA_CCER1` | 通道使能与输出极性 |
| `PWMA_CCMR1` | 通道模式（PWM 模式 1/2） |
| `PWMA_ARRH` / `PWMA_ARRL` | 自动重装值（决定周期） |
| `PWMA_CCR1H` / `PWMA_CCR1L` | 比较值（决定占空比） |
| `PWMA_ENO` | 输出使能（哪几路引脚输出） |
| `PWMA_PS` | 引脚映射（选哪个 IO 做 PWM 输出） |
| `PWMA_BKR` | 刹车 / 死区 |
| `PWMA_CR1` | 计数器使能 |
| `PWMA_EGR` | 软件更新事件 |

**建议：第一次用别自己啃手册。** 直接去 STC 官网下载 **「STC8H 系列演示程序」**，里面有现成的 PWMA 例程；或者在 STC-ISP 的「范例程序」里找到对应代码，改改就能用。

> **<span style="color: red;">提醒：</span>** 配置 PWMA 前通常要写 `P_SW2 |= 0x80;` 打开扩展寄存器访问，否则写进去的值不生效。

### 4. 12 位 ADC
STC8H 有 **12 位、15 通道**的 ADC（通道 0~14 对应各 ADC 引脚，通道 15 是内部 1.19V 基准）。

**使用要点：**
1. **做 ADC 输入的引脚必须设为「高阻输入」**（`PxM1 = 1, PxM0 = 0`）
2. 先打开 ADC 电源（`ADC_CONTR` 的电源位）
3. 启动转换 → 等标志位 → 读结果
4. 12 位结果分成两个寄存器存放，**注意对齐方式**

```c
#include <STC8H.H>
#include <stdio.h>

void ADC_Init(void) {
    P1M0 = 0x00;
    P1M1 = 0x01;          // P1.0 设为高阻输入（ADC 采样必须高阻）
    ADCCFG    = 0x2F;     // 结果右对齐 + 较慢的转换速度（更稳定）
    ADC_CONTR = 0x80;     // 打开 ADC 电源
}

unsigned int ADC_Read(unsigned char ch) {
    ADC_CONTR = 0x80 | (ch & 0x0F);    // 电源 + 通道号
    ADC_CONTR |= 0x40;                 // 启动转换
    while (!(ADC_CONTR & 0x20));       // 等转换完成标志
    ADC_CONTR &= ~0x20;                // 清标志
    return ((unsigned int)(ADC_RES & 0x0F) << 8) | ADC_RESL;   // 右对齐 12 位
}

void main(void) {
    unsigned int v;
    ADC_Init();
    while (1) {
        v = ADC_Read(0);          // 读通道 0
        Delay_ms(500);
    }
}
```

> **前提**：上面这段用到了 `Delay_ms()`，把第四章的延时函数一起复制过来即可。

> **说明**：`ADCCFG` 的位定义（结果对齐、转换速度）请对照 `STC8H.H` 或数据手册确认；不同头文件版本的名字可能略有差异。**采样电压不能超过 VCC（3.3V 或 5V）**，超了会烧引脚。

## 八、综合实战：按键 + 定时器 + 串口

> **前提**：本段用到第四章的 `Delay_ms()` 和第六章的 `UART1_Init()`，请一并复制过来。

把前面的东西串起来：按键切换模式，串口打印状态，定时器负责闪灯（**不用 delay，不阻塞按键**）。

```c
#include <STC8H.H>
#include <stdio.h>

sbit LED = P1^0;
sbit KEY = P3^2;

volatile unsigned int msTick = 0;   // volatile：中断里会改，主循环要读
unsigned char mode = 0;             // 0=慢闪 1=快闪 2=常亮

void Delay_ms(unsigned int ms) {
    unsigned int i, j;
    for (i = 0; i < ms; i++)
        for (j = 0; j < 1000; j++);
}

void Timer0_Init(void) {
    TMOD = (TMOD & 0xF0) | 0x00;
    TL0 = 0x30; TH0 = 0xF8;         // 24MHz / 12 → 1ms
    TR0 = 1; ET0 = 1; EA = 1;
}

void Timer0_ISR(void) interrupt 1 {
    msTick++;
}

char putchar(char c) {
    SBUF = c;
    while (!TI);
    TI = 0;
    return c;
}

void main(void) {
    unsigned int last = 0;
    P1M0 = 0x00; P1M1 = 0x00;
    P3M0 = 0x00; P3M1 = 0x00;

    Timer0_Init();
    UART1_Init();

    printf("系统启动，按键切换模式\r\n");

    while (1) {
        // ---- 按键检测 ----
        if (KEY == 0) {
            Delay_ms(20);
            if (KEY == 0) {
                mode = (mode + 1) % 3;
                switch (mode) {
                    case 0: printf("模式0：慢闪（1s）\r\n");   break;
                    case 1: printf("模式1：快闪（200ms）\r\n"); break;
                    case 2: printf("模式2：常亮\r\n");         break;
                }
                while (KEY == 0);
            }
        }

        // ---- 非阻塞闪灯：主循环照常跑 ----
        if (mode == 2) {
            LED = 0;
        } else {
            unsigned int period = (mode == 0) ? 1000 : 200;
            if (msTick - last >= period) {
                last = msTick;
                LED = !LED;
            }
        }
    }
}
```

> **这个程序的关键点**：`Delay_ms()` 会让 CPU 停在那里，按键就失灵了。改成「定时器打时间戳 + 主循环查询」，两者就能同时工作——这就是**非阻塞编程**的思路。

## 附录

### 1. 常用寄存器速查

| 寄存器 | 作用 | 备注 |
| --- | --- | --- |
| `P0` ~ `P7` | 端口数据 | 位寻址 |
| `PxM0` / `PxM1` | 端口模式 | **用前必设** |
| `TMOD` | 定时器模式 | T0 模式0 = 16 位自动重载 |
| `TCON` | `TR0` / `TF0` 等控制位 | 位寻址 |
| `SCON` | 串口控制 | `0x50` = 模式1 |
| `SBUF` | 串口数据 | 读=收，写=发 |
| `IE` / `EA` | 中断使能 | `EA` 是总开关 |
| `IP` / `IPH` | 中断优先级 | 4 级 |
| `AUXR` | 辅助寄存器 | `T0x12` / `T2R` / `EXTRAM` 等 |
| `ADC_CONTR` / `ADC_RES` / `ADC_RESL` | ADC 控制与结果 | |
| `P_SW2` | 扩展寄存器访问开关 | 最高位置 1 |

### 2. 常见问题速查

| 现象 | 原因 | 解决 |
| --- | --- | --- |
| 灯不亮 | **没设 IO 模式**（上电高阻） | 先写 `PxM0` / `PxM1` |
| 灯很暗 | 用了拉电流接法 | 改成灌电流（LED 接 VCC，引脚拉低点亮） |
| 编译报 `DATA space overflow` | 变量超了 128 字节 | 大数组加 `xdata` |
| 下载一直等待复位 | 没冷启动 | 先点下载，再给板子上电 |
| 定时时间差很多 | 主频设置和代码假设不一致 | 检查 STC-ISP 的 IRC 频率 |
| 串口乱码 | 波特率不匹配 | 双方一致；用 STC-ISP 计算器重算 |
| 中断进不去 | 没开 `EA` 或对应使能位 | 检查 `ET0` / `ES` 和 `EA` |
| 写入寄存器无效 | 扩展寄存器没使能 | 先 `P_SW2 |= 0x80;` |
| ADC 读数乱跳 | 引脚没设高阻输入 | `PxM1=1, PxM0=0` |
