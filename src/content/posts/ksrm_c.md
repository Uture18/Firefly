## 一、运算符与表达式求值

### 1. 基本数据类型

| 类型 | 字节 | 表示范围 | 格式符 |
| --- | --- | --- | --- |
| `char` | 1 | -128 ~ 127 | `%c` |
| `unsigned char` | 1 | 0 ~ 255 | `%c` |
| `short` | 2 | -32768 ~ 32767 | `%hd` |
| `int` | **4** | 约 ±21 亿 | `%d` |
| `unsigned int` | 4 | 0 ~ 42.9 亿 | `%u` |
| `long` | 4 / 8 | 视平台 | `%ld` |
| `long long` | 8 | ±9.2×10¹⁸ | `%lld` |
| `float` | 4 | 约 6~7 位有效数字 | `%f` |
| `double` | **8** | 约 15 位有效数字 | `%lf` |

> **注意**：谭浩强教材里 `int` 按 **2 字节**讲（16 位机时代），现代编译器是 **4 字节**。笔试如果考 `sizeof(int)`，按主流答案 **4** 写；如果题目明确说「16 位机」，则写 2。

### 2. 常量

| 类型 | 写法 | 说明 |
| --- | --- | --- |
| 十进制整数 | `123`、`-45` | |
| 八进制整数 | `0123` | **以 0 开头**，值是 83 |
| 十六进制整数 | `0x1A`、`0X1a` | 值是 26 |
| 长整型 | `123L` | |
| 实型 | `3.14`、`.5`、`1e-3` | `1e-3` = 0.001 |
| 字符常量 | `'A'`、`'\n'` | 单引号，一个字符 |
| 字符串常量 | `"A"` | 双引号，**结尾自动加 `'\0'`** |
| 转义字符 | `'\\'` `'\''` `'\0'` | |

**<span style="color: red;">`'A'` 和 `"A"` 不是一回事：</span>** `'A'` 占 1 字节，`"A"` 占 2 字节（'A' + '\0'）。

### 3. 算术运算符与整数除法
```c
int a = 5, b = 2;
printf("%d\n", a / b);       // 2   ← 整数除法，直接舍去小数
printf("%d\n", a % b);       // 1   ← 取余，两边必须都是整数
printf("%.2f\n", a / 2.0);   // 2.50 ← 有一边是实型，才是真除法
```

**取余的正负规则**：结果符号**与被除数相同**，即 `-5 % 2 == -1`，`5 % -2 == 1`。

**<span style="color: red;">必考陷阱：</span>** `5 / 2 * 3.0`
先算 `5/2 = 2`（整数），再算 `2 * 3.0 = 6.0`。**结果是 6.0，不是 7.5。**

### 4. 自增自减

| 写法 | 含义 | 特点 |
| --- | --- | --- |
| `i++` | 后缀 | **先用原值，再加 1** |
| `++i` | 前缀 | **先加 1，再用新值** |
| `i--` / `--i` | 同上 | 减 1 |

```c
int i = 5, j;
j = i++;        // j = 5，i 变为 6
j = ++i;        // i 变 7，j = 7
```

> **<span style="color: red;">考试红线：</span>** 一个表达式里**不要对同一变量多次自增**，比如 `i++ + i++`、`printf("%d,%d", i++, i++)`。这类写法结果**由编译器决定**（未定义行为），笔试一般不会考，遇到要警惕。

### 5. 赋值运算符与复合赋值
赋值运算符 `=` 是**右结合**，所以 `a = b = c = 5` 合法，等价于 `a = (b = (c = 5))`。

| 运算符 | 例子 | 等价于 |
| --- | --- | --- |
| `+=` | `a += 3` | `a = a + 3` |
| `-=` | `a -= 3` | `a = a - 3` |
| `*=` | `a *= 3` | `a = a * 3` |
| `/=` | `a /= 3` | `a = a / 3` |
| `%=` | `a %= 3` | `a = a % 3` |

**<span style="color: red;">注意：</span>** `a *= b + 1` 等价于 `a = a * (b + 1)`，**不是** `a = a * b + 1`。右侧整体参与运算。

### 6. 关系与逻辑运算符

| 运算符 | 含义 | 结果 |
| --- | --- | --- |
| `<` `<=` `>` `>=` | 比较 | 1（真）或 0（假） |
| `==` | 等于 | |
| `!=` | 不等于 | |
| `&&` | 逻辑与 | 两边都真才为 1 |
| `\|\|` | 逻辑或 | 有一边真即为 1 |
| `!` | 逻辑非 | 真变假、假变真 |

**短路求值（高频考点）：**

```c
int a = 0, b = 1;
if (a++ && b++) { }        // a++ 得 0（假）→ && 直接短路 → b++ 根本不执行
printf("%d %d\n", a, b);  // 输出：1 1
```

- `&&`：**左边为假，右边不执行**
- `||`：**左边为真，右边不执行**

> 记住这条，很多「求 a、b 最终值」的题就是靠它。

**C 语言没有布尔类型（C99 前）**：真就是**非 0**，假就是 **0**。`if (5)` 恒真，`if (-1)` 也恒真。

### 7. 位运算符

| 运算符 | 含义 | 例子（二进制） |
| --- | --- | --- |
| `&` | 按位与 | 6 & 3 = 110 & 011 = 010 = 2 |
| `\|` | 按位或 | 6 \| 3 = 110 \| 011 = 111 = 7 |
| `^` | 按位异或 | 6 ^ 3 = 110 ^ 011 = 101 = 5 |
| `~` | 按位取反 | ~6 = -7 |
| `<<` | 左移 | 6 << 1 = 12 |
| `>>` | 右移 | 6 >> 1 = 3 |

> 位运算只对**整型**有效，不涉及进位。

### 8. 条件运算符 `?:`
```c
表达式1 ? 表达式2 : 表达式3
```
**右结合**，可以嵌套：

```c
int a = 1, b = 2, c = 3;
int m = a > b ? a : b > c ? b : c;   // 等价于 a > b ? a : (b > c ? b : c)
// a > b 假 → 看 b > c，假 → 取 c = 3
```

### 9. 逗号运算符
逗号表达式的值是**最后一个表达式的值**，从左到右依次计算。

```c
int a = (1, 2, 3);     // a = 3
int b = 1, c = 2;
int d = (b++, c++, b + c);   // b=2, c=3, d=5
```

### 10. sizeof 运算符
返回**占用字节数**，结果类型是 `size_t`。

```c
printf("%d\n", (int)sizeof(int));      // 4
printf("%d\n", (int)sizeof(char));     // 1
printf("%d\n", (int)sizeof(double));   // 8
printf("%d\n", (int)sizeof("abc"));    // 4  ← 含结尾的 '\0'
char s[] = "abc";
printf("%d\n", (int)sizeof(s));        // 4  ← 数组大小
```

### 11. 运算符优先级（背下来）

| 优先级 | 运算符 | 结合方向 |
| --- | --- | --- |
| 1（最高） | `()` `[]` `->` `.` | 左 → 右 |
| 2 | `!` `~` `++` `--` `+`（正） `-`（负） `*`（解引用） `&`（取地址） `sizeof` | **右 → 左** |
| 3 | `*` `/` `%` | 左 → 右 |
| 4 | `+` `-` | 左 → 右 |
| 5 | `<<` `>>` | 左 → 右 |
| 6 | `<` `<=` `>` `>=` | 左 → 右 |
| 7 | `==` `!=` | 左 → 右 |
| 8 | `&` | 左 → 右 |
| 9 | `^` | 左 → 右 |
| 10 | `\|` | 左 → 右 |
| 11 | `&&` | 左 → 右 |
| 12 | `\|\|` | 左 → 右 |
| 13 | `?:` | **右 → 左** |
| 14 | `=` `+=` `-=` `*=` `/=` `%=` | **右 → 左** |
| 15（最低） | `,` | 左 → 右 |

**快速记忆口诀：**
> 单目 > 算术 > 移位 > 关系 > 相等 > 按位与、异或、或 > 逻辑与、或 > 条件 > 赋值 > 逗号

### 12. 类型转换
**自动转换**（隐式）：由低到高

```
char → short → int → unsigned → long → double
```

**强制转换**：`(类型名)表达式`，只是**临时转换，不改变原变量**。

```c
double d = 3.9;
int i = (int)d;          // i = 3（截断，不是四舍五入）
printf("%f\n", d);      // d 仍然是 3.900000
```

> **考点提示**
> - 整数除法和 `%` 的符号规则（`-5/2 = -2`，`-5%2 = -1`）
> - `i++` / `++i` 在表达式中的取值
> - `&&` / `||` 的短路
> - 复合赋值右侧整体参与运算
> - `5/2*3.0` 这类「先整除再乘实型」的陷阱
> - 优先级表里 `==` 高于 `=`（`if (a = b)` 是赋值！）

## 二、格式输入输出

### 1. printf 常用格式符

| 格式符 | 含义 | 例子 | 输出 |
| --- | --- | --- | --- |
| `%d` | 十进制整数 | `printf("%d", 42)` | 42 |
| `%c` | 单个字符 | `printf("%c", 'A')` | A |
| `%s` | 字符串 | `printf("%s", "abc")` | abc |
| `%f` | 实数（默认 6 位小数） | `printf("%f", 3.14)` | 3.140000 |
| `%lf` | double（scanf 必须用） | — | — |
| `%ld` | long | | |
| `%u` | 无符号 | `printf("%u", 10)` | 10 |
| `%o` | 八进制 | `printf("%o", 10)` | 12 |
| `%x` | 十六进制 | `printf("%x", 255)` | ff |
| `%%` | 输出一个百分号 | `printf("50%%")` | 50% |

### 2. 宽度、精度与对齐

| 写法 | 含义 | 例子 | 输出 |
| --- | --- | --- | --- |
| `%5d` | 宽度 5，**右对齐** | `printf("[%5d]", 42)` | [   42] |
| `%-5d` | 宽度 5，**左对齐** | `printf("[%-5d]", 42)` | [42   ] |
| `%08d` | 宽度 8，前面补 0 | `printf("%08d", 42)` | 00000042 |
| `%8.2f` | 总宽 8，保留 2 位小数 | `printf("[%8.2f]", 3.14159)` | [    3.14] |
| `%.2f` | 保留 2 位小数 | `printf("%.2f", 3.14159)` | 3.14 |
| `%.3s` | 只输出前 3 个字符 | `printf("%.3s", "abcdef")` | abc |

> **注意**：`%f` 默认输出 **6 位小数**，所以 `printf("%f", 2)` 输出 `2.000000`。

### 3. scanf 输入
**三条铁律：**
1. 除数组名/字符串外，**变量前必须加 `&`**
2. `double` 必须用 `%lf`（用 `%f` 会读错）
3. 格式串里如果有普通字符，**输入时必须原样输入**

```c
int a, b;
scanf("%d%d", &a, &b);        // 输入：3 4   （空格、回车、Tab 都行）

scanf("%d,%d", &a, &b);       // 输入必须写成：3,4  （逗号不能省）
```

| 格式符 | 匹配规则 |
| --- | --- |
| `%d` | 跳过前导空白，读一个整数 |
| `%f` `%lf` | 读实数 |
| `%c` | **读一个字符，不跳过空白**（回车也会被读进去！） |
| `%s` | 读字符串，**遇空格/回车停止**，自动加 `'\0'` |

**<span style="color: red;">经典陷阱：</span>** 先用 `scanf("%d", &n)` 再 `scanf("%c", &c)`

第一次输入数字后按的回车会留在缓冲区，第二个 `%c` 直接把回车读走了。**解决办法**：在 `%c` 前加空格，写成 `scanf(" %c", &c)`。

### 4. 字符输入输出

| 函数 | 作用 |
| --- | --- |
| `getchar()` | 从键盘读**一个字符** |
| `putchar(c)` | 输出**一个字符** |

```c
char c = getchar();
putchar(c);
putchar('\n');
```

> **考点提示**
> - `%5d` / `%-5d` / `%8.2f` 的输出结果（数空格！）
> - `%f` 默认 6 位小数
> - `scanf` 必须加 `&`；`double` 用 `%lf`
> - `%c` 会读走回车
> - `printf` 里 `%%` 输出百分号

## 三、选择结构

### 1. if 语句
```c
if (条件1) {
    语句组1;
} else if (条件2) {
    语句组2;
} else {
    语句组3;
}
```

**判断条件**：非 0 为真，0 为假。

```c
int x = 5;
if (x) { }          // 成立（x 非 0）
if (x = 0) { }      // ★ 这是赋值！x 变成 0，条件为假
if (x == 0) { }     // 这才是判断
```

> **<span style="color: red;">`=` 和 `==` 是笔试题第一大坑。</span>** 建议写 `if (0 == x)` 的习惯，写成 `if (0 = x)` 编译器直接报错，反而安全。

### 2. 悬空 else
```c
int a = 1, b = 2;
if (a > 0)
    if (b > 0) printf("A");
else
    printf("B");
```
**`else` 与最近的未配对 `if` 配对**，所以这里的 `else` 属于 `if (b > 0)`，不是外层。

### 3. switch 语句
```c
switch (表达式) {
    case 常量1:
        语句;
        break;
    case 常量2:
        语句;
        break;
    default:
        语句;
}
```

**规则：**

| 要点 | 说明 |
| --- | --- |
| 表达式类型 | **只能是整型或字符型**（不能是实型、字符串） |
| `case` 后 | 必须是**常量**，不能是变量 |
| `break` | **漏写会「穿透」执行下一个 case** |
| `default` | 位置任意，最后执行 |

```c
int x = 2;
switch (x) {
    case 1: printf("A");
    case 2: printf("B");      // 从这里开始
    case 3: printf("C");      // 没有 break，继续执行
    default: printf("D");
}
// 输出：BCD
```

> **考点提示**
> - `switch` 的穿透行为（算输出结果是高频题）
> - `case` 后不能是变量、不能是 `1.5`
> - 悬空 `else` 的配对
> - `if (a = b)` 与 `if (a == b)` 的区别
> - 逻辑表达式与短路结合

## 四、循环结构

### 1. 三种循环

| 循环 | 语法 | 特点 |
| --- | --- | --- |
| `while` | `while (条件) 语句;` | **先判断后执行**，可能一次都不执行 |
| `do-while` | `do 语句; while (条件);` | **先执行后判断**，至少执行一次 |
| `for` | `for (初始化; 条件; 增量) 语句;` | 最灵活，最常用 |

**三者可以互相转换。** `for` 的三部分都可省略，但分号不能省：

```c
for (;;) { }        // 死循环
```

### 2. break 与 continue（重点）

| 关键字 | 作用 |
| --- | --- |
| `break` | **立即跳出整个循环**（或 switch） |
| `continue` | **跳过本次循环剩余语句**，直接进入下一次 |

```c
int i, s = 0;
for (i = 1; i <= 5; i++) {
    if (i == 3) continue;    // 跳过 i=3
    s += i;
}
// s = 1 + 2 + 4 + 5 = 12
```

```c
int i, s = 0;
for (i = 1; i <= 5; i++) {
    if (i == 3) break;       // 到 3 就整个结束
    s += i;
}
// s = 1 + 2 = 3
```

> **<span style="color: red;">注意：</span>** `continue` 在 `while` 循环里如果放在 `i++` 之前，会导致 `i` 永远不增 → **死循环**。`for` 循环的增量表达式在 `continue` 之后仍会执行，所以没这个问题。

### 3. 循环嵌套
```c
int i, j;
for (i = 1; i <= 9; i++) {          // 外层：行
    for (j = 1; j <= i; j++) {      // 内层：列
        printf("%d*%d=%-3d", j, i, i * j);
    }
    printf("\n");
}
```
**执行次数**：外层 n 次 × 内层 m 次 = n×m 次。

> **考点提示**
> - `break` 只跳出**一层**循环（嵌套时）
> - `continue` 与 `for`、`while` 配合的差异
> - 循环次数的计算（注意 `<=` 还是 `<`）
> - `do-while` 至少执行一次
> - 常见算法：累加、阶乘、素数判断、水仙花数、斐波那契

## 五、数组与字符串

### 1. 一维数组
**定义**：`类型 数组名[长度];`

```c
int a[5];                        // 5 个元素，下标 0~4
int b[5] = {1, 2, 3, 4, 5};      // 完全初始化
int c[5] = {1, 2};               // 部分初始化：c[0]=1, c[1]=2，其余自动为 0
int d[] = {1, 2, 3};             // 省略长度，自动定为 3
```

**三条规则：**
1. 下标**从 0 开始**，`a[5]` 的合法下标是 `0~4`
2. **C 不检查越界**，`a[5]` 能编译通过，但会读写到别的内存 → 程序崩溃或数据错乱
3. 数组名代表**首地址**，是常量，不能赋值（`a = b` 非法）

### 2. 一维数组的常用算法
**求最大/最小值、求和、平均：**

```c
int a[10] = {3, 7, 1, 9, 5, 2, 8, 4, 6, 0};
int i, max = a[0], sum = 0;
for (i = 0; i < 10; i++) {
    if (a[i] > max) max = a[i];
    sum += a[i];
}
printf("max=%d, avg=%.2f\n", max, sum / 10.0);
```

**冒泡排序（必须会手写）：**
```c
void bubbleSort(int a[], int n) {
    int i, j, t;
    for (i = 0; i < n - 1; i++) {            // n-1 趟
        for (j = 0; j < n - 1 - i; j++) {    // 每趟比较次数递减
            if (a[j] > a[j + 1]) {
                t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
}
```

**选择排序：**
```c
void selectSort(int a[], int n) {
    int i, j, k, t;
    for (i = 0; i < n - 1; i++) {
        k = i;
        for (j = i + 1; j < n; j++)
            if (a[j] < a[k]) k = j;
        if (k != i) { t = a[i]; a[i] = a[k]; a[k] = t; }
    }
}
```

**二分查找（数组必须有序）：**
```c
int binarySearch(int a[], int n, int x) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (a[mid] == x)      return mid;
        else if (a[mid] < x)  low = mid + 1;
        else                  high = mid - 1;
    }
    return -1;              // 未找到
}
```

### 3. 二维数组
```c
int a[3][4];                        // 3 行 4 列
int b[2][3] = {{1,2,3}, {4,5,6}};   // 按行初始化
int c[2][3] = {1, 2, 3, 4, 5, 6};   // 等价写法（按行依次填充）
int d[][3] = {{1,2,3}, {4,5,6}};    // 行数可省，列数不能省
```

**<span style="color: red;">关键概念：</span>**
- 二维数组在内存中**按行连续存放**
- `a[0]` 是**第 0 行**（类型是 `int[4]`，一个一维数组）
- `a[1][2]` 是第 1 行第 2 列的元素
- `a` 的类型可以理解为「指向含 4 个 int 的一维数组的指针」

**遍历：**
```c
int i, j;
for (i = 0; i < 3; i++)
    for (j = 0; j < 4; j++)
        scanf("%d", &a[i][j]);
```

**二维数组作函数参数**（列数必须写）：
```c
void printMatrix(int a[][4], int rows) {   // 不能写 int a[][]
    int i, j;
    for (i = 0; i < rows; i++) {
        for (j = 0; j < 4; j++)
            printf("%4d", a[i][j]);
        printf("\n");
    }
}
```

### 4. 字符数组与字符串
**字符串的本质：以 `'\0'` 结尾的字符数组。**

```c
char s1[] = "hello";              // 6 字节：h e l l o \0
char s2[10] = "hello";            // 10 字节，后面补 \0
char s3[] = {'h','e','l','l','o'};// 5 字节，★ 不是字符串（没有 \0）
```

**<span style="color: red;">`sizeof` 和 `strlen` 的区别（必考）：</span>**

```c
char s[] = "hello";
printf("%d\n", (int)sizeof(s));   // 6  ← 数组占的字节数（含 '\0'）
printf("%d\n", (int)strlen(s));   // 5  ← 字符串实际长度（不含 '\0'）
```

### 5. 常用字符串函数（`#include <string.h>`）

| 函数 | 功能 | 示例 | 结果 |
| --- | --- | --- | --- |
| `strlen(s)` | 求长度（不含 `'\0'`） | `strlen("hello")` | 5 |
| `strcpy(d, s)` | 把 s 复制到 d | `strcpy(d, "abc")` | d = "abc" |
| `strcat(d, s)` | 把 s 接到 d 后面 | `strcat(d, "def")` | d 变长 |
| `strcmp(s1, s2)` | 比较 | `strcmp("abc","abd")` | **负数** |
| `strlwr(s)` | 转小写 | `strlwr("ABC")` | "abc" |
| `strupr(s)` | 转大写 | `strupr("abc")` | "ABC" |

**`strcmp` 的返回值规则（高频）：**

| 情况 | 返回值 |
| --- | --- |
| `s1 < s2` | **负数** |
| `s1 == s2` | 0 |
| `s1 > s2` | **正数** |

比较规则是**逐字符按 ASCII 码比较**，遇到第一个不同字符就决定大小。

> **<span style="color: red;">注意：</span>** 字符串**不能**用 `=` 赋值、不能用 `==` 比较！
> `s1 = s2` 是错的（数组名不能赋值），`s1 == s2` 比较的是**地址**不是内容。
> 必须用 `strcpy` 和 `strcmp`。

**自己实现 strlen 和 strcpy（考编程题常见）：**
```c
int my_strlen(char s[]) {
    int n = 0;
    while (s[n] != '\0') n++;
    return n;
}

void my_strcpy(char d[], char s[]) {
    int i = 0;
    while ((d[i] = s[i]) != '\0') i++;
}
```

> **考点提示**
> - 数组下标从 0，越界不报错
> - `sizeof` 与 `strlen` 的差异
> - 二维数组的列数不能省略
> - 字符串不能用 `=` 和 `==`
> - `strcmp` 返回值是正/负/0，不是具体的差值
> - 冒泡排序、二分查找要能默写

## 六、函数

### 1. 定义、声明与调用
```c
#include <stdio.h>

int add(int a, int b);      // ★ 函数声明（原型），告诉编译器函数长什么样

int main(void) {
    printf("%d\n", add(3, 5));   // 函数调用
    return 0;
}

int add(int a, int b) {     // 函数定义
    return a + b;
}
```

| 概念 | 说明 |
| --- | --- |
| **定义** | 写出完整函数体，**只能有一次** |
| **声明** | 只有函数头和分号，**可以有多次**，作用是让编译器提前知道 |
| **调用** | 使用函数 |
| 返回值 | `return` 带回；无返回值写 `void` |
| 默认返回 | 没写 `return` 时返回**不确定值** |

> **如果函数定义在调用之前，可以省略声明。** 定义在后、调用在前，就**必须声明**，否则编译器按隐式声明处理，可能出错。

### 2. ★ 值传递机制（最重要的考点）
**C 语言的参数传递只有一种：值传递（单向）。**

调用时，**实参的值复制一份给形参**，形参是实参的副本，**在函数内改形参，不影响实参**。

```c
void swap(int x, int y) {      // ❌ 这样交换不了
    int t = x;
    x = y;
    y = t;
}

int main(void) {
    int a = 3, b = 7;
    swap(a, b);
    printf("%d %d\n", a, b);  // 输出：3 7   ← 没变！
    return 0;
}
```

**正确做法：传地址（指针）：**
```c
void swap(int *x, int *y) {    // ✅ 传地址
    int t = *x;
    *x = *y;
    *y = t;
}

int main(void) {
    int a = 3, b = 7;
    swap(&a, &b);              // 传 a、b 的地址
    printf("%d %d\n", a, b);  // 输出：7 3
    return 0;
}
```

**数组作参数是例外吗？** 不是。数组名传进去会**退化为首地址**，所以函数内通过指针能改到原数组：

```c
void modify(int a[], int n) {
    a[0] = 100;                // 改的是原数组
}
```

### 3. 变量作用域

| 类别 | 定义位置 | 作用范围 | 生命周期 |
| --- | --- | --- | --- |
| **局部变量** | 函数/复合语句内部 | 本函数/本块 | 函数执行期间 |
| **全局变量** | 所有函数之外 | 整个程序 | 程序运行全程 |
| **形参** | 函数头 | 本函数 | 函数执行期间 |

**同名规则**：**局部优先**。局部变量会「遮蔽」同名的全局变量。

```c
int x = 1;                    // 全局
void f(void) {
    int x = 2;                // 局部，遮蔽全局
    printf("%d\n", x);       // 2
}
```

### 4. 存储类别：static（高频）

| 类别 | 关键字 | 特点 |
| --- | --- | --- |
| 自动变量 | `auto`（默认） | 每次进函数重新创建，**值不保留** |
| 静态局部 | `static` | **只初始化一次**，函数结束后值**保留** |
| 寄存器 | `register` | 建议放寄存器，速度快 |
| 外部 | `extern` | 声明变量在别处定义 |

**`static` 局部变量是笔试重点：**

```c
void f(void) {
    int n = 0;          // 每次进来都重新赋值
    n++;
    printf("%d ", n);
}
// 调用 3 次输出：1 1 1

void g(void) {
    static int n = 0;   // ★ 只初始化一次，值会累加
    n++;
    printf("%d ", n);
}
// 调用 3 次输出：1 2 3
```

### 5. 递归
```c
int fact(int n) {              // 求阶乘
    if (n <= 1) return 1;      // 递归出口
    return n * fact(n - 1);
}
```

**递归必须有两部分**：递归出口 + 递归公式。缺出口会无限递归导致栈溢出。

> **考点提示**
> - 值传递「改不动实参」（swap 题必考）
> - `static` 局部变量的累加效果
> - 局部变量遮蔽全局变量
> - 数组作参数实际传的是地址
> - 递归求阶乘/Fibonacci/汉诺塔

## 七、结构体与顺序表

### 1. 结构体类型声明
```c
struct Student {              // struct 是关键字，Student 是类型名
    int    no;                // 学号
    char   name[20];          // 姓名
    float  score;             // 成绩
};                            // ★ 分号不能少
```

**配合 `typedef` 使用更省事：**
```c
typedef struct {
    int   data[100];
    int   length;
} SeqList;                    // 之后可以直接写 SeqList，不用写 struct
```

### 2. 定义变量与初始化
```c
struct Student s1;                                // 定义变量
struct Student s2 = {1001, "张三", 92.5};         // 定义时初始化
SeqList L;                                        // 用 typedef 后
```

### 3. 成员访问

| 方式 | 适用 | 例子 |
| --- | --- | --- |
| `.` | 结构体**变量** | `s1.score = 90;` |
| `->` | 结构体**指针** | `p->score = 90;` |

**`p->score` 等价于 `(*p).score`**，注意括号不能少：`*p.score` 是错的（会先算 `p.score`）。

### 4. 结构体数组
```c
struct Student stu[3] = {
    {1001, "张三", 92.5},
    {1002, "李四", 78.0},
    {1003, "王五", 88.5}
};
printf("%s\n", stu[1].name);      // 李四
```

### 5. ★ 用结构体数组实现顺序表
> 顺序表 = **用一段连续的空间（数组）存数据 + 一个记录当前长度的变量**。这是考纲里明确要求掌握的内容。

**定义：**
```c
#include <stdio.h>
#define MAXSIZE 100

typedef struct {
    int data[MAXSIZE];        // 存放数据
    int length;               // 当前元素个数
} SeqList;
```

**初始化：**
```c
void InitList(SeqList *L) {
    L->length = 0;
}
```

**创建（输入 n 个元素）：**
```c
int CreateList(SeqList *L, int n) {
    int i;
    if (n > MAXSIZE) return 0;        // 空间不够
    for (i = 0; i < n; i++)
        scanf("%d", &L->data[i]);
    L->length = n;
    return 1;
}
```

**遍历（输出全部元素）：**
```c
void Traverse(SeqList *L) {
    int i;
    if (L->length == 0) { printf("空表\n"); return; }
    for (i = 0; i < L->length; i++)
        printf("%d ", L->data[i]);
    printf("\n");
}
```

**插入（在第 pos 个位置插入 x，pos 从 1 开始）：**
> 思路：**从后往前**把 pos 及之后的元素整体后移一位，腾出位置。

```c
int Insert(SeqList *L, int pos, int x) {
    int i;
    if (L->length >= MAXSIZE) return 0;          // 表满
    if (pos < 1 || pos > L->length + 1) return 0; // 位置非法
    for (i = L->length; i >= pos; i--)           // ★ 从后往前移
        L->data[i] = L->data[i - 1];
    L->data[pos - 1] = x;
    L->length++;
    return 1;
}
```

**删除（删除第 pos 个元素，用 e 带回）：**
> 思路：**从前往后**把 pos 之后的元素整体前移一位。

```c
int Delete(SeqList *L, int pos, int *e) {
    int i;
    if (pos < 1 || pos > L->length) return 0;    // 位置非法
    *e = L->data[pos - 1];                       // 保存被删元素
    for (i = pos; i < L->length; i++)            // ★ 从前往后移
        L->data[i - 1] = L->data[i];
    L->length--;
    return 1;
}
```

**查找（按值查找，返回位置，0 表示没找到）：**
```c
int Locate(SeqList *L, int x) {
    int i;
    for (i = 0; i < L->length; i++)
        if (L->data[i] == x) return i + 1;       // 返回 1 起始的位置
    return 0;
}
```

**排序（冒泡）：**
```c
void Sort(SeqList *L) {
    int i, j, t, flag;
    for (i = 0; i < L->length - 1; i++) {
        flag = 0;
        for (j = 0; j < L->length - 1 - i; j++) {
            if (L->data[j] > L->data[j + 1]) {
                t = L->data[j];
                L->data[j] = L->data[j + 1];
                L->data[j + 1] = t;
                flag = 1;
            }
        }
        if (flag == 0) break;                    // 本趟没交换，已有序
    }
}
```

**完整可运行的主函数：**
```c
int main(void) {
    SeqList L;
    int e;

    InitList(&L);
    printf("输入 5 个数：\n");
    CreateList(&L, 5);
    printf("原表：");
    Traverse(&L);

    Insert(&L, 2, 99);
    printf("在第 2 位插入 99 后：");
    Traverse(&L);

    if (Delete(&L, 3, &e))
        printf("删除第 3 位元素 %d 后：", e);
    Traverse(&L);

    printf("元素 88 的位置是：%d\n", Locate(&L, 88));

    Sort(&L);
    printf("排序后：");
    Traverse(&L);

    return 0;
}
```

> **<span style="color: red;">顺序表的三个易错点：</span>**
> 1. **插入从后往前移，删除从前往后移**（顺序反了会覆盖数据）
> 2. **位置 pos 从 1 开始**，数组下标从 0 开始，别混
> 3. 长度是 `L->length`，**有效下标是 `0 ~ length-1`**，插入的合法位置是 `1 ~ length+1`

> **考点提示**
> - 结构体声明末尾的**分号**
> - `.` 和 `->` 的适用场景
> - `p->x` 与 `(*p).x` 等价
> - 顺序表插入/删除的**移动方向和循环边界**
> - 结构体数组的初始化写法
